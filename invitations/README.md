# invitations/

Editörün **Yayınla → Yöntem 3** ile indirdiğiniz `.json` dosyalarını bu klasöre koyun.

```
invitations/elif-can.json  →  https://KULLANICI.github.io/dijital-davetiye/davetiye.html?d=elif-can
```

- Fotoğrafları JSON'a gömmek yerine `invitations/img/` klasörüne yükleyip editörde
  `invitations/img/kapak.jpg` gibi bağlantı verirseniz dosya küçük kalır.
- `ornek.json` örnek davetiyedir; tanıtım sayfası ve şablon önizlemeleri bunu kullanır.
- ⚠️ Herkese açık bir depodaki dosyalar herkes tarafından görülebilir.
